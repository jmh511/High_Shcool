# 효과음 · 배경음악 폴더

이 폴더는 **비워 두어도 됩니다.** 파일이 없으면 게임이 Web Audio API로
8비트 칩튠을 실시간 합성해서 재생하므로, 인터넷이 없는 교실에서도 소리가 납니다.

## 직접 구한 음원을 쓰고 싶다면

아래 이름으로 mp3 파일을 이 폴더에 넣기만 하면, 합성음 대신 그 파일이 재생됩니다.
(코드는 고칠 필요 없습니다. 파일이 없으면 자동으로 합성음으로 돌아갑니다.)

| 파일 이름 | 언제 재생되나 |
|---|---|
| `victory.mp3` | 최종 결과(우승자) 화면에서 반복 재생 |
| `lobby.mp3` | 대기실 배경음 (기본은 재생하지 않음, 아래 참고) |

## 대기실에도 배경음을 넣고 싶다면

`public/js/host.js` 의 `socket.on('room:created', ...)` 안에 아래 한 줄을 추가하세요.

```js
audio.playBgm('lobby');
```

## 음원을 고를 때 주의할 점

수업에서 트는 음악도 저작권이 적용됩니다. 무료로 쓸 수 있는 곡을 받으세요.
- **Pixabay Music** (pixabay.com/music) — 가입 없이 무료, 출처 표기 불필요
- **freesound.org** — 라이선스(CC0 권장)를 반드시 확인
- **OpenGameArt.org** — 8비트/칩튠 음악이 많음

기본 합성음은 코드로 만든 것이라 저작권 문제가 전혀 없습니다.
