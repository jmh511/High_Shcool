# 효과음 · 배경음악 폴더

이 폴더는 **비워 두어도 됩니다.** 파일이 없으면 게임이 Web Audio API로
8비트 칩튠을 실시간 합성해서 재생하므로, 인터넷이 없는 교실에서도 소리가 납니다.

## 직접 구한 음원을 쓰고 싶다면

아래 이름으로 mp3 파일을 이 폴더에 넣기만 하면, 합성음 대신 그 파일이 재생됩니다.
(코드는 고칠 필요 없습니다. 파일이 없으면 자동으로 합성음으로 돌아갑니다.)

| 파일 이름 | 언제 재생되나 |
|---|---|
| `lobby.mp3` | 대기실에서 참여자를 기다리는 동안 |
| `game.mp3` | 문제를 푸는 동안 계속 (작게 깔림) |
| `victory.mp3` | 최종 결과(우승자) 화면 |

세 곡 모두 반복 재생되며, 필요한 것만 넣어도 됩니다.
예를 들어 `victory.mp3` 만 넣으면 우승 화면에서만 그 파일이 나오고
나머지는 합성음이 나옵니다.

## 소리 끄고 켜기

화면 우측 상단에 **[🔊 효과음]** 과 **[🎵 배경음악]** 버튼이 따로 있습니다.
각각 독립적으로 끌 수 있고, 설정은 브라우저에 저장되어 새로고침해도 유지됩니다.
관리자 화면과 학생 기기가 서로 영향을 주지 않으므로,
선생님이 설명하실 때 프로젝터 화면의 배경음악만 꺼도 됩니다.

## 음량이나 곡을 바꾸고 싶다면

`public/js/audio.js` 의 `TRACKS` 에 각 곡의 음표와 음량(`vol`)이 들어 있습니다.
`vol` 값을 키우면 배경음이 커지고, `lead` / `bass` 배열의 음이름을 바꾸면 멜로디가 바뀝니다.

## 음원을 고를 때 주의할 점

수업에서 트는 음악도 저작권이 적용됩니다. 무료로 쓸 수 있는 곡을 받으세요.
- **Pixabay Music** (pixabay.com/music) — 가입 없이 무료, 출처 표기 불필요
- **freesound.org** — 라이선스(CC0 권장)를 반드시 확인
- **OpenGameArt.org** — 8비트/칩튠 음악이 많음

기본 합성음은 코드로 만든 것이라 저작권 문제가 전혀 없습니다.
